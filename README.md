# DICTOspheres

The front door to DICTO's work: [dictospheres.vercel.app](https://dictospheres.vercel.app).

**Kaleidohedra**, **Rhombiverse** and **Polyhedraverse**, three apps on one geometry, then DICTO's
other work and links. One static page (`index.html`), no build step, no tracking. To change a link,
edit `index.html` and push.
